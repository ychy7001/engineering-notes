# 发布与同步

## 一份正文，多处发布

文章源文件放在 `articles/<slug>/index.md`，图片和可公开数据放在同目录。优先修改源文件，再同步平台文章。GitHub 已公开不等于其他平台已经发布；各平台链接应在发布验证完成后再添加。

首篇文章建议：

- 标题：API 首字等待几十秒，后台却只统计 6 秒：一次公网入口延迟排查
- 分类：后端 / 运维相关分类，以平台实际可选项为准
- 标签候选：网络、后端，发布前核对平台实际标签
- 摘要：一次编程助手 API 请求延迟排查：通过本机与公网对照、正文接收计时和多来源实验，把模型耗时与入口延迟分开，最终保留橙云代理，替换 Tunnel 回源路径，并记录效果及尚未查明的问题。

平台发布时上传 `before.png`、`after.png` 到平台图片服务，替换正文中的相对路径。CSV链接改为GitHub上的公开结果文件链接。不要假设任意平台支持仓库相对链接或能稳定加载GitHub图片外链。

## 掘金 CLI 调查

核查日期：2026-10-19。暂未找到与 GitHub CLI 同等定位、具备官方文档和稳定认证授权流程的掘金官方文章发布 CLI。以下为第三方项目，仅按本次读取的 README 及部分源码描述能力，不代表实际账号端到端验证。

| 项目 | 本次核实的能力 | 当前判断 |
| --- | --- | --- |
| [ponyfly6/juejin-cli](https://github.com/ponyfly6/juejin-cli) | 浏览、搜索、读取及导出文章 | 不适合上传原创文章 |
| [alanyf/juejin-cli](https://github.com/alanyf/juejin-cli) | 读取文章及部分账户互动操作；README 未展示文章发布流程 | 不作为发布器选型依据 |
| [Thneoly/juejin-publisher](https://github.com/Thneoly/juejin-publisher) | 声明支持浏览器登录、Markdown建草稿、发布及状态检查；源码有对应命令 | 可进一步评估的候选，尚未安装或用账号实测 |

对发布器读取的版本为 [`fb103756a4334ac302177f091d485fd4ba60b23e`](https://github.com/Thneoly/juejin-publisher/tree/fb103756a4334ac302177f091d485fd4ba60b23e)。它使用非官方网页接口和本地浏览器 Cookie，不是OAuth或官方开发者Token。

部分源码检查发现：浏览器自动发现路径面向 Windows Chrome/Edge；登录流程还会额外打开知乎登录页；登录态保存在脚本目录的 `.juejin.env`，设备元数据在 `_wf/`。因此不能直接认定它能在无桌面的 Linux 服务器上开箱即用。

## 后续接入方式

推荐由作者在自己的浏览器完成掘金登录。选定工具并检查实现后，先做账号身份核对和单篇草稿验证，再处理正式发布。文章写作、数据校验、配图和平台格式转换可以交给助手；短信验证码或扫码登录仍由作者完成。

工具和登录数据应放在内容仓库之外的私有工作目录。不要在聊天中粘贴 Cookie、将浏览器会话文件提交到仓库，或对公网开放浏览器调试端口。当前仓库没有安装任何发布插件，也没有包含登录凭证。

如果接入第三方发布器，还需核验正文图片上传、相对链接转换、草稿重复创建与发布结果确认。CLI存在不等于这些环节已经可用；本轮未向掘金创建草稿或发布文章。
